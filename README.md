# Advanced GSC SEO

Google Search Console for one site, designed by enterprise SEO consultants.

The plugin connects Cursor and Grok Bot to the hosted server at `https://www.advancedgsc.com/api/mcp`. Install is free. Sign-in is Google. No API key.

## Install

1. Add the plugin from the marketplace, or add the server URL above in your client's MCP settings.
2. Choose **Connect** and sign in with the Google account that has Search Console access.
3. Ask the agent to call `get_capabilities`.
4. If no site is pinned, ask it to call `select_property` and pick one.

## What Free includes

Free is the full Search Console connection for one website, which is enough for most site owners.

- Every Search Console tool, for 1 property
- 16 months of history
- 300 rows per response
- URL inspection, 15 per day
- Advanced Search Console tools, 10 per day each
- Core Web Vitals whole-site check, 10 per day
- 100 successful tool calls every 7 days

Paid plans are optional. They add more properties, remove the daily limits, and add GA4, Google Ads, and SEO research tools.
